Bharath G P Portfolio
Static portfolio website built with HTML, CSS and JavaScript. No installation or build step is needed.

Project structure
bharath-portfolio/
  index.html
  css/style.css
  js/script.js
  assets/Bharath_G_P_Resume.pdf
  README.md
Run in VS Code
First unzip the file. VS Code cannot run a project from inside a zip.

Option 1, Live Server:

Open the unzipped folder in VS Code (File, then Open Folder)
Install the Live Server extension
Right-click index.html and choose Open with Live Server
Option 2, terminal (needs Node.js installed):

In VS Code open Terminal, then New Terminal
Run npm start
The site opens at http://localhost:5500
Option 3: double-click index.html to open it in your browser.

If the page opens as plain text, open it through one of the options above instead of the VS Code editor preview.

Upload to GitHub
Run in the VS Code terminal inside this folder:

git init
git add .
git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/bharath56721/My_Portfolio_.git
git push -u origin main
Deploy with GitHub Pages
Open the repository, then Settings, then Pages
Set Branch to main and folder to / (root), then Save
The site goes live at https://bharath56721.github.io/My_Portfolio_/
Deploy with Netlify or Vercel
Import the repository, leave the build command empty and keep the root folder as the publish directory.
