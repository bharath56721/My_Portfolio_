## 🚀 Run the Project in VS Code

First, extract the ZIP file before opening the project in VS Code.

### Option 1: Using Live Server (Recommended)

1. Open VS Code.
2. Select **File → Open Folder**.
3. Choose the extracted portfolio folder.
4. Install the **Live Server** extension.
5. Right-click `index.html`.
6. Select **Open with Live Server**.

### Option 2: Using Node.js

1. Open the project folder in VS Code.
2. Open Terminal → New Terminal.
3. Run the following command:

```bash
npm start
```

4. Open your browser at:

http://localhost:5500

*Note: This option requires a suitable Node.js server script or package configuration.*

### Option 3: Direct Browser

Double-click `index.html` to open the portfolio directly in your browser.

**Note:** If the page opens as plain text, use Live Server or another local web server instead.

## 📤 Upload Project to GitHub

Run these commands in the VS Code terminal from inside your project folder:

```bash
git init

git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/bharath56721/My_Portfolio_.git
git push -u origin main
```

## 🌐 Deploy Your Portfolio Website

### Option 1: GitHub Pages

1. Open your GitHub repository.
2. Go to **Settings → Pages**.
3. Under Build and Deployment, select **Deploy from a branch**.
4. Select branch: `main`.
5. Select folder: `/ (root)`.
6. Click **Save**.

Your portfolio website will be available at:

https://bharath56721.github.io/My_Portfolio_/

### Option 2: Netlify

1. Visit https://www.netlify.com/.
2. Sign in using your GitHub account.
3. Select **Add new project → Import an existing project**.
4. Connect your GitHub repository.
5. Select `My_Portfolio_`.
6. Keep the build command empty.
7. Set the publish directory to the project root (`.`).
8. Click **Deploy**.

### Option 3: Vercel

1. Visit https://vercel.com/.
2. Sign in using GitHub.
3. Import your portfolio repository.
4. Keep the framework preset as **Other**.
5. Leave the build command empty.
6. Set the output directory to `.`.
7. Deploy your project.
